# Portal de Notícias - Grupo 3

## Introdução

Este projeto foi desenvolvido para a disciplina **Arquitetura e Desenho de Software**, ministrada pela professora **Milene Serrano**.

A proposta consiste na criação de um **Portal de Notícias**, com ênfase em Atualidade e Conteúdo UGC (User-Generated Content), baseado em qualquer portal de notícias para inspiração, podendo ser em versão site, desktop ou aplicativo móvel.
